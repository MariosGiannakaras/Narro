# Upload inbox

Drop **all raw Blitzit videos and their transcripts/captions here**.

You do not need to organize them first. Mixed filenames and mixed file types are acceptable. The later analysis pass will catalog, pair, classify, timestamp, and route the evidence.

Preferred behavior:

- keep the original video file intact;
- keep the original transcript/caption file intact;
- if a transcript obviously belongs to a video, similar filenames help but are not required;
- include any companion note file if you know the Blitzit version, date, OS/display setup, or what the recording demonstrates;
- do not overwrite an older raw recording with a newer one.

Common video formats in this folder are tracked through Git LFS. Text transcripts remain ordinary Git files.

After upload, the durable analysis will be maintained in `docs/BLITZIT_VIDEO_EVIDENCE.md`.
