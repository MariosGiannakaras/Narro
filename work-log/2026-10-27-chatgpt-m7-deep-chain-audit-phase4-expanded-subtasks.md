Exception or stale write before commit rolls back; completed write commits once, and old client stale versions reject rather than overwrite other window's changes. `src-tauri/src/persistence/subtasks.rs` validates ranked records and UUID/corrupted payloads.
6. `src/useSubtaskProjection.ts:17–79` binds current task/list, installs board invalidation listener **before** initial read, increments request revision and tracks the active mount lease; rejects stale owner/list/task child IDs; ignores out-of-order/disposed read completions. `FocusLiveSubtasks::refreshSubtasksAndBoard` awaits child + Board snapshots together, verifies the child's parent ID and that the board has matching total/completed counts before publishing the updated task; if the write succeeded but readback fails, `committedRefreshBlockedRef` synchronously blocks further edits and shows **"Subtask change was saved, but authoritative Focus progress could not refresh"**, requiring reopening Focus. This prevents a stale browser retry from duplicating a committed action. If a newer accepted projection supersedes the write's read, its stale completion returns without replacing that newer state.
