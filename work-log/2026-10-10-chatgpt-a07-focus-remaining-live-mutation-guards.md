The authoritative backend may reject the second as already absent; never allege actual native duplicate permanent deletion, but a false error/competing side effects are code-plausible. `ListBoard.tsx` provides precedent `deleteInFlightRef` guarded across its own deletion (around lines 1736–1766).

- `makeTaskLive` (around lines 754–779): has only `mutationPendingTaskId` render gating around `snapshotTimerSession` and `startTimerTask`/`switchTimerTask`. Two handlers within one React render can issue overlapping timer commands despite persistence authority; test must preserve timer identity/time.
